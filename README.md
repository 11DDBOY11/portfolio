# Darshan Dashyal Portfolio

This is a personal portfolio website for Darshan Dashyal, a Computer Science & Engineering student focused on full-stack development, machine learning, and AI-powered products.

The site is built as a single-page static website and showcases his background, technical skills, projects, certifications, goals, and contact information.

## Overview

The portfolio includes:

- Hero section with introduction and profile summary
- About section with education and background
- Skills section covering programming, AI, web, and data work
- Certifications section with IBM, Google, and Salesforce credentials
- Projects section with GitHub and live demo links
- Goals section highlighting future direction
- Contact section with social and email links
- Responsive, animated styling with custom cursor effects

## How to Run

Because this is a static front-end website, you can run it in two simple ways:

### Option 1: Open directly

1. Open `index.html` in any browser.
2. The page will render without needing a build step.

### Option 2: Run a local web server

From this folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Notes

- The project is suitable for GitHub Pages, Netlify, Vercel static hosting, or any simple hosting platform.
- Project links and social links are embedded directly in the page.
